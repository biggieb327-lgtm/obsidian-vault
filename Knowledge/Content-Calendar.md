## Publishing Pipeline

1. **Check** Notion/Obsidian for draft content (standalone draft pages, unwritten Research Log, unfiled `.md`).
2. **Finalize** one piece — complete, date-stamped, statused.
3. **Publish** to the appropriate platform:
   - Finalized research → **Notion Hermes Research Log** (structured archive).
   - Long-form docs / working notes → **Obsidian** (git-versioned).
   - Briefs/digests → **Matrix** home channel.
4. **Update** this calendar + today's daily note.

> Note: This calendar lives in Obsidian because the Notion database API (v2025-09-03) could not apply schema properties at create time, leaving a schema-less DB that cannot hold structured rows.
